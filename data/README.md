# 연구 데이터

- `raw/`: 내려받은 원문. 수정하지 않습니다.
- `processed/`: 원문에서 정리한 기본 입력.
- `analysis/final/`: 본 분석의 고정 패널·공간 연결·RDF 및 확장 데이터.
- `analysis/experiments/`: 예비 실험 전용 파생 데이터.
- `analysis/baseline_two_industry/`: 기존 두 업종 결과 재현용 고정 입력.
- `analysis/kopis_snapshots/`: 검증된 KOPIS 회차별 스냅샷.
- `analysis/kopis_collection/`: 수집 과정에서 작성하는 자료.
- `analysis/legacy/`: 이전 분석 데이터.

회귀 계수·검증 결과표는 `../results/`, 사람이 읽는 결과 해석은 `../reports/`에 있습니다. CSV의 미제공 매출을 0으로 바꾸지 않습니다.
