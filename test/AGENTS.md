# Preliminary test 전용 규칙

- 사용자가 요청한 실험 폴더다. 이 폴더의 결과를 본 연구의 검증 결과로 사용하지 않는다.
- 새 분석 코드는 이 폴더의 `notebooks/*.ipynb`에만 저장한다. `.py` 분석 파일을 만들지 않는다.
- 결과·파생 자료·보고서는 각각 이 폴더의 `reports/`, `data/` 아래에 저장한다. `final/`, 기존 원자료·결과를 수정하지 않는다.
- 모든 시도와 실패·미추정을 기록한다. 탐색 후 선택한 결과에 통상적 p값의 검증력을 부여하지 않는다.
- 실제자료 탐색, 의도적 오용, 효과를 주입한 모의자료를 파일·표·서술에서 구분한다.
- 미제공 매출을 0원으로 대체하지 않는다. 분기 자료를 일별 자료로 만들지 않는다. 네트워크 요청을 하지 않는다.
- 한국어 설명과 짧은 코드·표/그래프·해석을 구성하고 새 커널 전체 실행을 확인한다.
