# jupyter-notebook

이 프로젝트의 분석·전처리·시각화·수집 코드는 모두 이 폴더의 Jupyter Notebook에 있다. 별도 `.py` 분석 소스는 새로 만들지 않는다. 노트북은 **한국어 설명 → 짧은 코드 → 표·그림 → 해석** 순서로 쓰여 있어서, 실행하지 않고 읽기만 해도 무엇을 왜 했는지 따라갈 수 있다.

```text
jupyter-notebook/
├── 20261006/            현재 분석 ← 지금 쓰는 곳
│   ├── 00_전체실행.ipynb        기초 입력·기준선 (notebooks 01→08)
│   ├── 01_시간대확장_실행.ipynb  공연 시간창 (notebooks 09→11)
│   ├── 02_수정분석_실행.ipynb    수정 분기 분석 (12→13→보고서)
│   ├── notebooks/               분석 노트북 01~13
│   ├── report-notebooks/        보고서·진단 노트북 01~09
│   ├── data-collection/         수집·자료 확보 노트북 01~05 (분석 실행에 미포함)
│   └── metadata/                고정 입력 명세와 사전 분석 계획
├── 20261005/            이전 분석 보관본 (수정하지 않음)
│   ├── notebooks/               노트북 01~16
│   └── scripts/                 초기 수집 스크립트 5개
└── sandbox/             독립 실험 (본 연구에 반영하지 않음)
```

## 어디서부터 실행하나

새 커널에서 실행 노트북 하나를 위에서 아래로 실행하면, 그 안의 노트북들이 순서대로 각각 새 커널에서 실행된다. 분석 실행에는 수집이 들어 있지 않으며 네트워크와 인증키가 필요 없다.

| 목적 | 실행 노트북 | 내부 실행 순서 | 결과 위치 |
|---|---|---|---|
| 기초 입력·기존 기준선 | [`20261006/00_전체실행.ipynb`](20261006/00_전체실행.ipynb) | `notebooks/` 01 → 08 | `reports/20261006/` |
| 공연 시간창 확장 | [`20261006/01_시간대확장_실행.ipynb`](20261006/01_시간대확장_실행.ipynb) | `notebooks/` 09 → 11 | `reports/20261006/time_windows/` |
| **현재 수정 분석** | [`20261006/02_수정분석_실행.ipynb`](20261006/02_수정분석_실행.ipynb) | 12 → 13 → `report-notebooks/` 09 → 08 | `reports/20261006/revised_quarterly/` |
| 독립 실험 | [`sandbox/00_전체실행.ipynb`](sandbox/00_전체실행.ipynb) | 01 → 02 → 03 → 05 → 06 → 07 → 04 | `sandbox/reports/` |

> [!WARNING]
> 실행 노트북은 해당 분석의 파생 자료와 결과를 다시 쓴다. 기존 결과를 그대로 둔 채 재현만 확인하려면 [`environment/verify_reproduction.ipynb`](../environment/verify_reproduction.ipynb)를 쓴다. 이 노트북은 별도 작업 폴더에서 실행하고 수치를 대조한다. 같은 결과 경로에 쓰는 노트북을 동시에 실행하지 않는다.

## sandbox/ — 독립 실험

같은 자료로 p값이 어떻게 달라지는지 보는 실험 폴더다. 실제자료 사후 탐색, 의도적 오용 시연, 합성 효과 주입 모의실험을 구분해 기록한다. 결과는 본 연구의 검증 결과로 쓰지 않는다. 자세한 내용은 [sandbox/README.md](sandbox/README.md), 폴더 전용 규칙은 [sandbox/AGENTS.md](sandbox/AGENTS.md)에 있다.

| 하위 폴더 | 내용 |
|---|---|
| `notebooks/` | 실험 노트북 01~07 |
| `data/` | 실험 전용 파생 자료 |
| `metadata/` | 실험 계획(`lab_plan.json`, 보호 대상 파일 해시)과 방법 참고문헌 |
| `reports/` | 실험별 결과 CSV·요약 JSON·그림, 580개 전수 검정 장부, 읽기용 HTML |

## 노트북을 쓸 때의 규칙

- 모든 노트북은 **새 커널에서 위에서 아래로** 실행할 수 있어야 한다.
- 경로는 공통 초기화 셀이 정한 `PROJECT_ROOT`와 `project_path(...)`로 만든다. 이전 루트나 개인 절대 경로를 넣지 않는다.
- 과거 경로가 담긴 JSON은 `project_json_loads(...)`로 읽는다. 원본 JSON은 고치지 않는다.
- 분석 노트북은 네트워크 요청을 하지 않는다. 수집은 사용자가 요청한 경우에만 `data-collection/`에서 한다.
- 커널은 `graduation-project (Python 3.12)`를 쓴다. 환경은 [`environment/README.md`](../environment/README.md)를 따른다.
