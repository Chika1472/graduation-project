## 해석할 때 핵심

실제자료 580개 검정 중 보정 전 p<0.05는 16개였습니다. 전체 BH와 Bonferroni 보정 후에는 모두 0개였습니다. 이는 효과가 없다고 입증한 결과도, 유의한 16개가 모두 진짜라는 결과도 아닙니다.

PPML 한식 총매출은 PPML 20개 내 보정에서는 유의했습니다. 그러나 다른 기준·모형도 함께 시도한 전체 탐색 범위를 생략하면 안 됩니다. 전체 580개 장부와 보고서에서 원 p값, 실험군 내 보정, 전체 보정을 함께 확인하세요. 보정은 사후 탐색을 독립 검증으로 바꾸지 않습니다.

같은 행을 복제하거나 원하는 관계에 불리한 관측을 제거하면 작은 p값을 만들 수 있었습니다. 이 시연의 p값은 정당한 증거가 아닙니다. 고정효과 제거는 지역 간 차이를 포함하는 다른 질문으로, 행 복제와는 구분했습니다.

개별 공연장 좌석을 연결할 수 있었지만, 현재 좌석은 과거 좌석이나 실제 관객 수가 아닙니다. 좌석과 일정의 공동 가용률 90%를 요구한 표본에서는 대학로(혜화역)·홍대입구역(홍대)이 모두 제외됐습니다. 핵심상권의 일정 원문 확인과 과거 좌석 검증이 중요한 후속 과제입니다.

## 실행

프로젝트의 기존 Python 과학계산 환경에서 `00_전체실행.ipynb`를 위에서 아래로 실행합니다. 01 → 02 → 03 → 05 → 06 → 07 → 04 순서로 각각 새 커널에서 실행하며, 동시 실행은 피합니다. 고정된 기존 입력이 있어야 하며 네트워크 수집은 하지 않습니다. 생성 결과는 이 폴더 내부에만 저장합니다.

- `metadata/lab_plan.json`: 목적과 보호 대상 305개 파일의 원래 SHA-256
- `reports/execution_manifest.json`: 단계별 실행 상태와 소요 시간
- `reports/report_notes.json`: 해석 범위, 보고서 근거, 화면 검증 상태
- `reports/*_summary.json`: 실험별 검증·가정·누락 정보
- `reports/notebooks/`: 실행 완료된 노트북의 읽기용 HTML
- `data/`: 실험 전용 파생 자료

이 폴더의 결과나 기준은 본 연구에 자동 반영되지 않습니다. 인증키를 읽거나 저장하지 않습니다. 미제공 매출을 0원으로 대체하지 않고, 분기 자료를 일별 자료로 해석하지 않습니다.
