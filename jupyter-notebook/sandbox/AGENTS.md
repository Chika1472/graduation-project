# Preliminary 통계·측정 실험 전용 규칙

- 이 규칙은 `jupyter-notebook/sandbox/`에 적용한다. 프로젝트 루트의 `AGENTS.md`도 따른다. 아래에서 ‘이 폴더’는 sandbox, ‘루트’는 `C:\Coding\graduation-project`를 뜻한다.
- 사용자가 요청한 독립 실험 폴더다. 이 폴더의 결과를 본 연구의 검증 결과로 사용하거나 본 연구에 자동 반영하지 않는다.
- 새 분석 코드는 이 폴더의 `notebooks/*.ipynb`에만 저장한다. 별도 `.py` 분석 파일을 만들지 않는다.
- 결과·보고서는 이 폴더의 `reports/`, 파생 자료는 `data/` 아래에 저장한다. 루트의 `jupyter-notebook/20261006/`, `dataset/`의 기존 입력, 본 연구·이전 분석 결과는 읽기 전용으로 사용한다.
- 전체 실행 진입점은 이 폴더의 `00_전체실행.ipynb`이다. 01 → 02 → 03 → 05 → 06 → 07 → 04 순서로 각각 새 커널에서 실행하며, 같은 결과 경로에 쓰는 동시 실행은 피한다.
- 모든 시도와 실패·미추정을 기록한다. 탐색 후 선택한 결과에 통상적 p값의 검증력을 부여하지 않는다. 전체 탐색 범위와 다중검정 보정을 함께 보고한다.
- 실제자료 탐색, 의도적 오용, 효과를 주입한 모의자료를 파일·표·서술에서 구분한다. 현재 좌석 수와 예정회차를 과거 좌석 수나 실제 관객 수로 해석하지 않는다.
- 미제공 매출을 0원으로 대체하지 않는다. 분기 자료를 일별 자료로 만들지 않는다. 네트워크 요청을 하지 않으며 인증키를 읽거나 저장하지 않는다.
- 한국어 Markdown 설명 → 짧은 코드 셀 → 표·그래프 → 해석 순서로 작성하고 새 커널 전체 실행을 확인한다.
- 별도 가상환경을 만들지 않고 루트의 `.venv/`와 `environment/`를 사용한다. 실행은 루트의 `start-jupyter.cmd`, 커널은 `graduation-project (Python 3.12)`를 사용한다.
- 과거 입력 명세·결과 파일의 경로는 루트의 `environment/project_paths.ipynb`로 해석한다. 이 폴더의 `metadata/lab_plan.json`에 기록된 원래 보호 대상·해시를 검증 편의를 위해 수정하지 않는다. 승인된 경로·문서 변경만 루트의 `environment/path_migration.json`에서 추적한다.
- 기존 실험 결과를 보존하며 재현을 점검할 때는 루트의 `environment/verify_reproduction.ipynb`를 사용한다. 검증 작업 폴더의 복사본을 실제 실험 소스나 입력으로 사용하지 않는다.
