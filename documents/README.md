# documents

사람이 읽는 문서를 모아 둔 폴더다. 코드를 실행하지 않고도 연구의 계획과 결과를 따라갈 수 있도록 연구계획서, 참고문헌, 읽기용 보고서를 한곳에 두었다.

```text
documents/
├── proposals/    연구계획서 (요약본·상세본)
├── references/   참고 논문과 학습 자료 (PDF)
└── reports/      읽기용 HTML 보고서 7편
```

## proposals/ — 연구계획서

| 문서 | 형식 | 내용 |
|---|---|---|
| [졸업프로젝트_연구계획서_개정안.md](proposals/졸업프로젝트_연구계획서_개정안.md) | 요약본 | 제출 양식에 맞춘 한 장짜리 계획서. 배경·동기·주제·데이터·분석 방법·전략·예상 결과 |
| [졸업프로젝트_상세연구계획서_개정안.md](proposals/졸업프로젝트_상세연구계획서_개정안.md) | 상세본 (2026-09-22 기준) | 현실성 평가, 데이터 확보 방법, 노출 측정, 패널·공간 결합, 온톨로지, 에이전트 동작, 실증 방법, 평가 설계, 12주 계획, 지도교수 상담용 정리 |

계획서는 연구를 시작할 때의 설계다. 이후 범위가 두 업종에서 외식업 10종으로 넓어졌고, 노출 지표도 등록 공연 ID 수에서 예정 시작회차로 바뀌었다. 바뀐 내용은 [메인 README](../README.md)와 아래 보고서에 정리했다.

## reports/ — 읽기용 보고서

분석 노트북이 만든 HTML 보고서 가운데 읽을 만한 것을 알아보기 쉬운 이름으로 복사해 두었다. 원본은 `reports/` 아래 각 분석 폴더에 있으며 내용은 같다.

| 읽는 순서 | 보고서 | 다루는 질문 | 원본 위치 |
|:---:|---|---|---|
| 1 | 공연 활동과 주변 외식업 매출의 관계 종로구·마포구 분석 보고서 | 등록 공연 ID 수와 총매출·야간 비중의 업종별 관련성 (기준선) | `reports/20261006/analysis_report/report.html` |
| 2 | 공연·외식업 분석 추가 검토 결과 | 점포 정의, 매출 미제공, 공간 중첩, 정보집중도에 대한 독립 검토 | `reports/20261005/audit_20261005/report.html` |
| 3 | 공연시간창_분석보고서 | 공연 종료 후 0~3시간 등 시간창과 시간대별 매출 패턴 | `reports/20261006/time_windows/공연시간창_분석보고서.html` |
| 4 | 공연·외식업 분석에서 유의한 관계가 뚜렷하지 않은 이유 | 비유의성을 측정·식별변동·표본·정밀도로 나눈 진단 | `reports/20261006/null_diagnostics/report.html` |
| 5 | 공연 예정회차와 주변 외식업 매출 수정 분석 결과 | 진단을 반영한 예정 시작회차·매출액 분석 (현재 결과) | `reports/20261006/revised_quarterly/report.html` |
| 6 | 일자시간대매출_자료확보_검토 | 일자·시간대 매출 자료(B079)의 확보 방법과 적용 가능성 | `reports/20261006/data_access/` |
| 7 | 유의한 결과는 어떻게 만들어지는가 | 사후 탐색·의도적 오용·합성 효과 주입 실험 (본 연구 미반영) | `jupyter-notebook/sandbox/` 종합 보고서 |

처음 읽는다면 **1 → 4 → 5** 순서를 권한다. 기준선 결과, 그 결과가 왜 뚜렷하지 않았는지, 그리고 이를 반영해 무엇을 바꿨는지가 차례로 이어진다.

> [!TIP]
> GitHub 웹에서 HTML 파일을 열면 소스 코드가 보인다. 저장소를 내려받은 뒤 브라우저로 열어야 그래프와 표가 제대로 표시된다.

7번 보고서는 독립 실험 폴더(`jupyter-notebook/sandbox/`)의 결과다. 업종별 정밀도의 차이를 보여 주는 참고자료이며, 본 연구의 검증 결과로 쓰지 않는다.
