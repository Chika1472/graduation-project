비유의성 진단을 반영한 현재 분석은 `12_분기예정회차_데이터셋` → `13_분기매출액_수정분석` → `report/09_수정표본_보조진단` → `report/08_수정분석_결과보고서` 순서다. 02 실행 노트북이 각각 새 커널에서 실행한다. [수정 결과 보고서](../reports/final/revised_quarterly/report.html)와 [실행 기록](../reports/final/revised_quarterly/execution_manifest.json)을 함께 확인한다.

공연 활동은 **상권 중심점에서 500m 이내 시설의 분기 예정 시작회차**로 정의한다. 시작일정을 재구성할 수 있는 후보 ID 비율이 100%인 표본이 기본이며, 총매출액과 21~24시 매출액을 각각 분석한다. 이 비율은 실제 회차·관객의 정확도가 아니다. 일반 요일 일정의 반복, 현재 좌표·경계, 상권 전체 매출이라는 한계는 유지된다. 90% 가용 표본·기존 최단거리 연결·같은 표본의 공연 ID 수 비교와 공간 공분산 민감도를 사전에 고정했다. 명세는 [revised_quarterly_plan.json](metadata/revised_quarterly_plan.json)에 있다.

수정 데이터는 `../data/analysis/final/revised_quarterly/`, 결과는 `../reports/final/revised_quarterly/`에 저장한다. 기존 기준선과 시간창 결과를 덮어쓰지 않는다. 아래 00은 기초 입력 및 기존 분석을 재현하는 실행 진입점이다. 현재 수정본은 이미 검증된 기초 패널과 고정 명세를 읽으므로 00을 매번 다시 실행할 필요는 없다.

수정 주모형은 5,015행·114상권·10종이며, 네 사양의 총 80개 결과 모두 보정 전 p≥0.05다. 이 결과를 공연의 실제 소비 효과가 없다는 증거로 해석하지 않는다. 특히 일정 가용률 100% 표본은 대학로(혜화역)·홍대입구역(홍대)을 제외하므로, 공연 밀집 중심상권에 일반화할 수 없다. 상세 수치·불확실성·표본 선택은 위 보고서에 수록했다.

## 검토 후 반영한 점

점포를 일반·프랜차이즈·전체로 구분했다. 기존 일반점포 0·매출 양수 95행은 프랜차이즈가 있는 사례이므로 점포 부재 오류로 해석하지 않는다. `store_count`가 쓰이는 부분은 일반점포의 호환용 별칭이다. 매출 모집단 확인 전에는 점포당 매출을 제시하지 않는다.

주분석은 점포를 통제하지 않는 고정효과 모형이다. 민감도 분석에서는 일반점포 통제와 전체점포 통제를 구분한다. 업종별 회귀 정보의 집중도와 개별 신뢰구간이 다중비교 보정 구간이 아니라는 점도 표시한다.

다음 사항은 실행 성공과 별개로 남는 연구 한계다.

- 작은 상권·업종의 선택적 매출 미제공과 업종별 분석 지역 차이.
- 여러 상권이 같은 공연을 공유하는 구조와 잔차 공간 상관의 미검증.
- 공연 ID 수와 실제 상연 횟수·관객 수의 차이.
- 현재 상권 경계·시설 위치를 과거 분기에 적용하는 한계.

결과는 자료가 제공된 상권·업종의 분기 관련성이다. 유의하지 않은 결과를 관계가 없다는 증명으로 해석하지 않는다. 07·08은 부분 RDF와 오프라인 분석 도구이며 LLM의 자연어 계획이나 웹 서비스는 아직 연결하지 않았다. 여기서 최종본은 **현재 구현된 분석 파이프라인의 정리본**을 의미한다.

## 수집 도구

수집은 전체 실행에 포함하지 않는다. 기존 자료로 분석할 때는 실행할 필요가 없다.

- [KOPIS 수집기](KOPIS_수집기.cmd), 상태 조회 명령: `final/kopis.cmd status`.
- [KOPIS 상세 수집](collection/01_KOPIS_상세수집.ipynb).
- [서울시 원자료 수집](collection/02_서울시_원자료수집.ipynb): 기본은 오프라인 검증, 수집은 `SEOUL_COLLECT=1`로 명시.
- [KOPIS 스냅샷 검증](collection/03_KOPIS_스냅샷검증.ipynb).
- [수집기 오프라인 검증](collection/04_KOPIS_CLI_오프라인검증.ipynb).
- [일자·시간대 매출 자료 확보](collection/05_일자시간대매출_자료확보.ipynb): 공식 설명서·이용 안내·공개 가공 샘플을 수집하고 적용 가능성을 검토한다. 기본은 고정 원문 오프라인 검증이며 재수집은 `TIME_SALES_FETCH=1`로 실행한다. [검토 결과와 신청 초안](../reports/final/data_access/일자시간대매출_자료확보_검토.html). 샘플은 실제 매출 분석에 투입하지 않는다. B079 원본은 캠퍼스 내부 분석 자료이며, 6개 시간 구간을 정확한 공연 종료 후 3/6시간 매출로 해석할 수 없다.

수집 후 공용 `metadata/`가 바뀌어도 이 최종본의 고정 입력은 자동 교체하지 않는다. 새 회차를 채택할 때 최종 명세를 별도 갱신하고 전체 분석을 다시 실행한다.
