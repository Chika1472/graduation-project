# 읽는 보고서

[보고서 모아보기](index.html)에서 시작하세요.

- `main/revised_quarterly/`: 현재 분기 분석 보고서
- `main/baseline/`: 기초 분석 보고서·노트북 읽기본
- `main/time_windows/`: 공연 시간창 확장 분석
- `main/null_diagnostics/`: 비유의성 원인 진단
- `main/data_access/`: 추가 매출 자료 확보 검토
- `experiments/`: 본 연구와 구분되는 예비 실험 보고서
- `audits/`: 데이터·방법 검토 기록
- `legacy/`: 이전 버전의 읽기본

CSV·JSON·그림 원본·실행 기록은 `../results/`에 있습니다. 이 폴더에는 읽는 문서와 안내만 저장합니다.
